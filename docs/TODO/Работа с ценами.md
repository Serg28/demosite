## Правила роботи з цінами (`Price` ValueObject)

`app/ValueObjects/Price` використовує `bcmath` — **точна арифметика без float-помилок**.

**Обов'язково** використовувати `Price` при:
- Накопиченні (sum по кількох позиціях): `$total = $total->add(Price::from($price)->multiply($qty))`
- Знижках: `Price::from($base)->multiply($discountRate / 100)`
- Комісіях: `Price::from($amount)->multiply($rate)->divide(100)`
- Будь-яких ланцюжках `+ * /` з грошима

**Дозволено `round()`** лише на зовнішніх API-межах (одна операція, не накопичення):
- Конвертація в копійки для гейтвею: `(int) round($price * 100)` або `Price::from($price)->toInt()`
- Фінальна сума замовлення перед відправкою в API (одне читання з БД, без арифметики)

**Заборонено:** `$total += $price * $qty` у циклі — float накопичується і дає похибку.

`Price::toInt()` = kopecks (bcmul * 100). `Price::toFloat()` = для виводу/збереження.

Формат копеек только через конфиг cart: 'format' => [
        'decimals' => 0,
        'decimal_point' => '.',
        'thousand_separator' => '',
    ],
