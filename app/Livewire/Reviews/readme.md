Компоненты на базе установленного пакета Commentify.
Comments - сохраняет функционал базового пакета. Позволяет вывести комментарии для текущей модели
Company - выводит комментарии для страницы О компании (работает точно также как и Comments)
Product - выводит комментарии товара сайта
Comment - вывод для одного комментария


Часть шаблонов (базовых) находится в resources/views/vendor/commentify/livewire
Для переопределенных компонентов - в resources/views/livewire/reviews
