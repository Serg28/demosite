Шаблон кнопки старта отмены заказа, два шаблона для окна подтверждения и результата операции.
Нужно настроить под нужды.

Пример использования:

1) В шаблоне вывода заказов делаем вызов `<livewire:profile.order.button-cancel-order :order="$currentorder->id">`  где order - ID заказа
2) В странице/шаблоне (можно внизу) делаем вызов <`livewire:profile.order.cancel-order />` который выводи попап с подтверждением действия, а потом с результатом.
Это можно переделать под потребности, напр., сделать другой тип модалок.
3) Проверить, чтобы сами компоненты livewire присутствовали и в них прописаны нужные шаблоны и логика под нужды проекта.
